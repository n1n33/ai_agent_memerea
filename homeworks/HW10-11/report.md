# HW10-11 – компьютерное зрение в PyTorch: CNN, transfer learning, detection/segmentation

## 1. Кратко: что сделано

- Для части A выбран датасет **STL10**: 10 классов, изображения 96×96, официальные train/test split — удобно для сравнения моделей без дополнительных усилий по подготовке данных.
- Для части B выбран датасет **Pascal VOC 2012**, трек **segmentation**: датасет хорошо задокументирован, pretrained DeepLabV3 напрямую поддерживает его классы, что позволяет сосредоточиться на постобработке и метриках без переобучения.
- В части A сравнивались: простая CNN без аугментаций (C1), та же CNN с аугментациями (C2), pretrained ResNet18 с замороженным backbone (C3), pretrained ResNet18 с частичным fine-tuning слоя layer4+fc (C4). В части B сравнивались два режима постобработки маски сегментации: базовый argmax (V1) и argmax с удалением мелких компонент связности (V2).

## 3. Данные

### 3.1. Часть A: классификация

- Датасет: `STL10`
- Разделение: официальный `train` split разбивается 80/20 (seed=42) на train/val; официальный `test` split используется только для финальной оценки лучшей модели.
- Базовые transforms: `ToTensor()` + `Normalize(mean=[0.5,0.5,0.5], std=[0.5,0.5,0.5])`
- Augmentation transforms: `RandomHorizontalFlip()` + `RandomCrop(96, padding=4)` + `ToTensor()` + `Normalize(mean=[0.5,0.5,0.5], std=[0.5,0.5,0.5])`
- Комментарий: STL10 содержит 10 классов (airplane, bird, car и др.), изображения 96×96 RGB. Train split — 5000 изображений (500 на класс), test — 8000. Задача считается умеренно сложной: классы визуально различимы, но небольшой размер train-выборки делает transfer learning особенно выгодным. Для ResNet18 изображения дополнительно ресайзятся до 224×224 с ImageNet-нормировкой.

### 3.2. Часть B: structured vision

- Датасет: `Pascal VOC 2012`
- Трек: `segmentation`
- Что считается ground truth: пиксельные маски из официальной аннотации VOCSegmentation (val split); foreground — класс 15 (person) по VOC-палитре; пиксели с меткой 255 (ignore) обнуляются перед оценкой.
- Какие предсказания использовались: argmax по каналам выхода `DeepLabV3_ResNet50` (pretrained на COCO), ресайз входного изображения до 256×256.
- Комментарий: VOC Segmentation — стандартный бенчмарк с 21 классом (включая фон). Класс `person` (15) выбран как наиболее часто встречающийся foreground, что даёт достаточное количество примеров для оценки. DeepLabV3 обучен на COCO, которое включает VOC-классы, поэтому инференс без дообучения даёт осмысленные предсказания. Постановка задачи — бинарная сегментация foreground vs background для одного класса.

## 4. Часть A: модели и обучение (C1-C4)

Опишите коротко и сопоставимо:

- C1 (simple-cnn-base): SimpleCNN (2 conv блока: 32→64 фильтра, MaxPool, Flatten, Linear 128→10), transforms без аугментаций.
- C2 (simple-cnn-aug): та же архитектура SimpleCNN, добавлены RandomHorizontalFlip и RandomCrop(96, padding=4) на этапе обучения; val всегда оценивается без аугментаций.
- C3 (resnet18-head-only): pretrained ResNet18 (IMAGENET1K_V1), все параметры заморожены, обучается только `fc` (512→10).
- C4 (resnet18-finetune): pretrained ResNet18 (IMAGENET1K_V1), разморожены `layer4` и `fc`, остальные слои заморожены.

Дополнительно:

- Loss: `CrossEntropyLoss`
- Optimizer(ы): `Adam`, lr=1e-3; для C3/C4 оптимизируются только размороженные параметры
- Batch size: 64
- Epochs (макс): 5
- Критерий выбора лучшей модели: максимальная `best_val_accuracy` по всем 4 экспериментам

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)

### Если выбран segmentation track

- Модель: `DeepLabV3_ResNet50` из `torchvision.models.segmentation`, pretrained weights=`DEFAULT` (COCO)
- Что считается foreground: класс 15 (person) по VOC/COCO палитре; маска бинаризуется как `(prediction == 15)` и `(target == 15)`
- V1: базовая постобработка — argmax по каналам logits, бинаризация по выбранному классу без дополнительных преобразований
- V2: альтернативная постобработка — argmax + удаление связных компонент площадью менее 500 пикселей (`scipy.ndimage.label`); цель — убрать шумовые артефакты на периферии
- Как считался mean IoU: `intersection / union` по бинарным маскам pred и target для каждого изображения, усреднение по всем изображениям где присутствует foreground; значения `nan` (пустой union) исключались из среднего
- Считались ли дополнительные pixel-level метрики: да — `pixel_precision` = TP/(TP+FP), `pixel_recall` = TP/(TP+FN)

## 7. Анализ

SimpleCNN показала val_accuracy около 0.49–0.52 на STL10 за 5 эпох. Это ожидаемо: архитектура неглубокая, а STL10 содержит всего 5000 train-изображений — недостаточно для обучения мощных признаков с нуля. Аугментации (C2) дали прирост, но небольшой: 5 эпох слишком мало, чтобы сеть успела воспользоваться разнообразием аугментированных примеров в полной мере.

Pretrained ResNet18 показал принципиально иной результат уже в режиме head-only (C3: 0.761): замороженный backbone извлекает богатые ImageNet-признаки, которые хорошо переносятся на STL10, поскольку оба датасета содержат натуральные изображения схожих категорий. Partial fine-tuning (C4: 0.834) улучшил результат ещё на 7 п.п. — размороженный layer4 адаптировал высокоуровневые признаки под специфику STL10, не разрушая низкоуровневые детекторы в ранних слоях.

Главный вывод по transfer learning: даже 5 эпох достаточно для значимого улучшения при наличии хорошей инициализации. Разница между C4 и C1 в 34 п.п. при одинаковом числе эпох наглядно показывает ценность претрейна.

В части B модель DeepLabV3 без дообучения уверенно выделяет силуэты людей, но на краях объектов появляются мелкие изолированные компоненты. Переход от V1 к V2 убирает этот шум: precision растёт, recall почти не падает — компоненты менее 500px в большинстве случаев являются ложноположительными артефактами, а не частями реального объекта. Mean IoU при этом незначительно меняется, что говорит о том, что основной вклад вносят именно крупные ошибки локализации (несовпадение границ), а не шум.

## 8. Итоговый вывод

В качестве базового конфига для классификации изображений предпочтительна схема C4 (pretrained ResNet18 + разморозка layer4+fc): она даёт наилучшую val и test accuracy при разумных затратах на обучение. Главный урок по transfer learning: при небольшом датасете замороженный pretrained backbone уже даёт сильный результат, а частичное размораживание верхних слоёв позволяет адаптировать признаки без риска переобучения. Для detection и segmentation ключевое понимание — разница между локализацией и классификацией: mean IoU штрафует за неточность границ, тогда как pixel accuracy может быть высокой даже при плохой маске (если фон доминирует). Корректный выбор foreground-класса и обработка ignore-пикселей критически важны для получения осмысленных метрик.
